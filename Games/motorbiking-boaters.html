Motorbiking boaters (student proposal)

Assessment: ✅ Fit · Category: Games · Assessed: 2026-09-21 · Status: awaiting instructor approval

Proposal (as submitted): An endless side-scrolling freestyle jet-ski game: the player is an aspiring rider training for the BlueBull Jet-Ski Freeride Competition, chaining stunts and combos while staying on the jet ski as long as possible without wiping out. Tricks are performed with phone interactions — swipes, taps, holds and tilts — combined in sequences to trigger different stunts; simple tricks give small time bonuses, complex tricks/combos give more time and score multipliers, and failed tricks subtract time (a risk-and-reward loop). The course escalates with more obstacles and trick terrain the longer the player survives; the goal is high scores. USP: tricks are integral to survival — chain increasingly difficult stunts to extend game time in a high-risk / high-reward environment. Genre: casual arcade sports / endless runner. Platform: Mobile, native Android. Named technical features: gyroscope/accelerometer motion controls + gesture recognition; a server-side gacha + user-accounts solution; a real-time physics engine simulating the jet-ski + water interaction (arcade inertia, jumping above water); and procedural endless level generation. Named core-requirement notes: a C++ loop stable under heavy particle effects (splashes/sparks after a combo landing); tilt-to-move via gyro/accelerometer; a custom level-testing tool for designers to tweak procedural-level and player parameters without touching code. Design features: gesture-based freestyle trick system; a combo & scoring system; the risk-or-reward system; progressive difficulty & survival.

References:

  • Alto's Odyssey Press Kit — Team Alto (an endless side-scroller built on a one-touch trick system: chain combos, physics-based movement, procedurally generated terrain, escalating biomes — the endless-trick-survival + procgen precedent)
  • OlliOlli World on Steam (a 2D side-scrolling trick game where you string tricks, grinds and spins into combos for score multipliers, landing cleanly or wiping out — the gesture-input trick-combo-scoring precedent)
  • Jetpack Joyride — Wikipedia (the benchmark one-touch endless mobile arcade runner: procedurally varied hazards, coins, an in-run slot machine + a "Stash" of gadgets/cosmetics — the endless-mobile + gacha/economy precedent, incl. a "Wave Rider" jet-ski vehicle)

How each requirement applies:

Platform fit: Main: Native mobile (Native Android — the stated platform; device: Pixel 9a) — tilt-to-move and swipe/tap/hold trick input are native-touch/sensor-first; the Native PC build is the development/tools vehicle (the level-testing tool). Extended: a Linux server the team sets up by M2 (full use T2) hosting the gacha service + user accounts, plus an external database (Firebase or a server store) for accounts, cosmetics and high scores.
Front end: A side-scrolling 2D renderer (the rider + jet-ski, water surface, obstacles, trick terrain and escalating background) with the trick/combo/timer HUD and heavy splash/spark particle VFX, plus the gacha and score screens. Languages: Native — Kotlin Native Android UI + the C++ engine via JNI (Android Studio); OpenGL ES drawn in a GLSurfaceView for the realtime 2D; Web/desktop — SDL2/3 + OpenGL ES for the PC dev/tools build.
Back end: The C++ engine core (fixed-timestep loop, arcade jet-ski + water-interaction physics with above-water inertia, gesture/gyro trick recognition, the combo/scoring/time economy, procedural endless generation and the particle systems) + a server-side gacha & user-accounts service. Languages: C++ (engine); the gacha/accounts service on the Linux server.
Backend scope: Local now, server-ready (T2) — the gacha + accounts + high-score seam set up & basic-tested on the Linux host by M2, full use in T2.
  • Loop and/or service: the C++ loop is load-bearing — it runs the arcade jet-ski/water physics (buoyancy, above-water inertia, landing), the gesture/gyro trick recognition and combo resolution, the risk/reward time economy, the endless procedural scroll and the heavy splash/spark particle effects, holding a stable frame rate under a combo's particle burst.
  • Data-driven: trick definitions and their gesture sequences, scoring/time-bonus values, obstacle/terrain pieces and their difficulty weights, player/physics parameters and the gacha cosmetic tables are all hot-reloadable data authored via the level-testing tool — designers tune without touching code.
  • 2D: side-scrolling sprite rendering + splash/spark particle VFX (custom-rendered). 3D: not needed. Networking: no real-time multiplayer — the gacha/accounts/high-score calls are async client↔︎server (Application Communication ✅); a real-time Networking System is optional (🔵).
  • Custom tool: the level-testing tool — tweak procedural-generation weights, obstacle/terrain sets and player/physics parameters with live preview, without recompiling.
  • External DB: accounts, cosmetics/gacha inventory and high scores. Auth ⏭️: user accounts. Analytics ⏭️: optional — trick-attempt/failure and drop-off telemetry for difficulty tuning.

Monetization note (design condition): the gacha must be designed to the module's clean-monetization rule — cosmetic-only, no pay-to-win, transparent odds, no manipulative loops (addressed in the M2 Design goal D8 below). A gacha that gated gameplay power or hid odds would fail that rule; keep it purely cosmetic.

Track Goals & Team Composition

Recommended composition: 6 CS + 1 Design + 2 Art (9) — the game reads by its trick animation and water/particle VFX, so two artists carry the rider + jet-ski, the many trick animations, the water/spray effects, the escalating environments and the gacha cosmetics; a single designer owns the gesture-trick vocabulary, the combo/scoring/risk-reward economy, the procedural-difficulty curve and the (clean) gacha economy (rules: min 1 Design mandated, max 9 total, D+A ≤ 3; see team-formation.pdf). If the trick/economy/gacha systems outgrow one designer, trade the 2nd artist for a 2nd designer. Scope note (advisory): arcade water physics + gesture tricks + combo/risk-reward + procedural endless + a server gacha + the editor is a large surface — treat single-run survival with the water physics, a handful of tricks + combos, the risk/reward timer and the level-testing tool as the M1/M2 floor, with the full trick set, escalating procgen and the server gacha as the stretch.
